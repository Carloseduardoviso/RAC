Sobre este MVP

As operações e o patrimônio seguem sintéticos. O simulador produz variações aleatórias; os sinais vêm de uma regra de momentum, não de um modelo de IA treinado.

O resultado inclui taxa ilustrativa de 0,1% por lado e câmbio fictício de R$ 5 por USDT. Não prevê slippage real, spreads variáveis ou outras condições de mercado.

O RAC consulta cotações públicas reais e, quando o administrador solicita, lê a carteira Spot pela API com permissão exclusivamente de leitura. O histórico real em BRL representa estimativas de mercado, sem conciliação de lucro. A Testnet está disponível para verificações públicas. Não existem endpoints para ordens reais, saques ou pagamentos.
